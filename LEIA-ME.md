# Cantinho do Apoio — protótipo

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: design responsivo e tipografia.
- `script.js`: janela de comentário, seleção/compactação de imagem, mural e armazenamento local.

## Testar
Abra `index.html` no navegador, toque em **Comentar**, escreva uma mensagem e, se quiser, escolha uma imagem.

## Limitações importantes
- As publicações ficam no `localStorage` do navegador e aparelho usados para abrir a página.
- As publicações não são compartilhadas entre visitantes ou dispositivos.
- Para um mural público real, no qual todos vejam e publiquem mensagens/imagens, será necessário conectar um backend ou banco de dados, com regras de segurança, moderação e limites de upload.
- A fonte Fredoka vem do Google Fonts; precisa de internet para carregar se não estiver em cache.
- Para GitHub Pages, envie os três arquivos (`index.html`, `style.css`, `script.js`) para a mesma pasta publicada.
